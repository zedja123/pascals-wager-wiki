    Sanity

    Abnormal state

    Abnormal state

    Character state

    Trigger
    sanity at or below 70% of maximum (70 of 100)
    Next stage
    Lunatic state at 50%
    Hero effects
    one penalty and usually one bonus per hero
    Trophies
    attack, defence and resistance trophies switch on
    Time tracked
    5 hours in total gives the achievement "Crazy"

    The Abnormal state is what the interface calls the middle stage of Sanity loss. Once sanity is at or below 70% of the maximum, the hero no longer behaves normally: each character receives a set of changes that are listed in the character's stat page, and trophies built around the state become active. Nothing in this stage locks sanity, so a drink of Elixir of Sanity can bring you back to Normal. The deeper stage is the Lunatic state.

    What every hero gets#

    • Equipped trophies with an "Abnormal" line work (attack, physical defence, or all elemental resistances; see Sanity talents and trophies).
    • Ordinary enemies in the area get an aggressive flag (see Abnormal state#Enemies turn aggressive).
    • Talents that read "in the Abnormal State" are now eligible (with the exceptions noted there).
    • Chapter bosses and some elites that carry a "sanity drop" roll an extra drop table (usually a 40% chance of Anthozoan Bones) when they die while you are not Normal. Lunatic counts too. The tables are listed per boss in Bosses#How boss fights work.
    • Time spent in the state (Abnormal or Lunatic, any hero) is counted for the achievement "Crazy" (18,000 seconds, 5 hours, in total across the whole save; Achievements). Entering it for the first time completes a tutorial-trigger quest (quests 19015 and 19016 are the first-time Abnormal and first-time Lunatic markers).
    • Lunatic is just Abnormal plus the lock described on the other page: every effect below still holds.

    Enemies turn aggressive#

    The moment sanity first drops out of Normal, the game gives every ordinary enemy in the area (not bosses, not stationary or non-hostile ones) a "crazy" flag and a red glow. The flag is cleared when sanity returns to Normal, so it belongs to the whole Abnormal and Lunatic range, not to the Lunatic state alone. Enemy AIs with a second branch for that flag (about 26 attack scripts, for example 20001, 20004, 20011 and 20049) then:

    • stop idling in their threat/stalking stance as often and pick the attack state about three times out of four instead;
    • chain combo moves back to back (the crazy branch repeatedly re-checks the combo continuation moves).

    This is read from the behaviour trees; the numeric weight is 3 : 1 attack to threat (inferred meaning). Enemies that spawn later in the same visit are not re-flagged until the state changes again (inferred).

    Hidden mechanics#

    • The penalty talents are reductions. The English text of "Adapt to Abnormality" can be read as stacking more penalty; in the code each one lowers the penalty by multiplying it by (1 - talent percent). Level 2 of the Norwood talent leaves only -10%.
    • Wounds on Viola ignore blocking. The check that lets a block cancel the wound looks at a "guard" flag that this status does not have, so even a perfectly timed block still wounds her.
    • Benita's resistance starts working as soon as the gauge is full, not at the first potion. The three resistance statuses are build-up statuses (StackAddPer 40 / 35 / 25, StackSubPer 2): a status only counts as present once its gauge has reached 100, and then the potion code halves the heal. See Benita#Abnormal state.
    • Terrence's dodge restriction is data, not code. Two dodge rows carry a "normal only" flag; the talent adds a permission for those two moves.
    • "Lucky Madness" is not limited to this state. The drop code adds its bonus on every kill. See Sanity talents and trophies#Lucky Madness by hero.
    • An unused Viola constant. Her define file also holds a 30% item-value reduction (SanItemValueSubRate 300) that no code reads; only Benita's 50% version is used.
    • Norwood's Toughness bonus is a flat point value. It is +10 points (+15 with the talent), not a percentage like every other penalty on this page.
