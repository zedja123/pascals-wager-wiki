    This page is the reference data for Trophy reforging. The same grades also set the main-property values that enhancement raises. For each trophy it lists the order in which reforging walks through sub-properties, and the values each value tier gives for each level of the sacrificed trophy.

    How to read this page#

    • Tier is the trophy's value tier, taken from its first main property (a property id has the digits FF S T L: FF = family, S = stat slot, T = tier digit, L = level 1-6; the tier label is FF followed by T, so id 10101 is tier 100 and id 12221 is tier 122). Reforging keeps the tier and only changes the level digit, so a trophy's tier never changes.
    • The cycle column is the effective cycle in Forward order (stats the trophy already has are removed). Backward is the same list read right to left. After the last entry the cycle wraps to the first.
    • Value cells list the sub-property for a sacrificed trophy at +0/+1/+2/+3/+4/+5.

    Hidden mechanics#

    • The tier, not the category, sets the cycle. Families 10-12 are offense, 20-22 defense and 30-32 endurance, so a Scars trophy with a family-21 first property (Double-star Brooch) reforges into defensive stats.
    • Broadly, tiers 11x give the lowest values, 10x the middle and 12x the highest (the ranges overlap, so compare the table). Tier 123, 223 and 323 are the best tier of their cycle.
    • The sacrifice's level matters about as much as the tier. In tier 100, a +5 sacrifice doubles Atk vs X (5% to 10%) and triples Attack (+15 to +45) compared with a +0 sacrifice; across tiers, a +0 sacrifice gives Attack anywhere from +8 (tier 110) to +40 (tier 123). Since you cannot change a trophy's tier, the sacrifice's level is the only part you control.
    • Tiers 101 and 111 step unevenly for Atk vs Humanoid/Beasts/Sendril: tier 101 goes +2.5%, +1.5%, +1.5%, +1.5%, +2.5% (6% to 15.5%) and tier 111 goes +2.5% then +1.5% four times (4.5% to 13%). Every other offense tier uses an even step. The first jump (+0 to +1 sacrifice) is therefore unusually large in these two tiers. The same uneven grades appear in enhancement, for example Crazy Mask's Atk vs Humanoid (see Trophy enhancement#How stat values grow).
    • Tier 122 is the only tier where Atk vs Sendril (8% to 18%) differs from Atk vs Humanoid and Atk vs Beasts (9% to 21.5%), most likely a data entry error (Atk vs Sendril rows 12421-12426).
    • Health in the defense cycle grows faster than linearly at low tiers (e.g. tier 200: 35/60/90/125/165/210). That makes a +5 sacrifice especially valuable there.
