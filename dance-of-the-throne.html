    Dance of the Throne

    Dance of the Throne

    Add-on content

    Store name
    Dance of the Throne
    Internal id
    dlcarcade (flag DLC_ARCADE)
    Adds
    Arcade mode, playable Elena, Arcade achievements and talents
    Related item
    Elena outfit "Enigma" (hero11007, flag DLC_ELENA)
    Needs
    Nothing for the main run; some stages need Deep into the Dark Mist or Tides of Oblivion
    Achievement tab
    Tab 6, ids 60001 to 60015

    Dance of the Throne is the name the game's store and menu text give to its arcade add-on. In the game files the same content is called Arcade everywhere (ArcadeHero, ArcadeMonsterProperty, FS_Arcade, IapData.DLC_ARCADE), and the English name appears only in the downloadable-content text, the Arcade difficulty intro text and the Arcade achievement tab. The name is confirmed in the game text, so this is not a guess: the DLC entry dlcarcade is titled Dance of the Throne.

    The add-on's blurb, in short: an arcade challenge in which the Obsession of all the Demiurges has been called back to Solas to take revenge, with the Demiurge leader Elena as a new playable hero who fights with a pair of blades.

    What belongs to the add-on#

    ContentWhere it shows upDetails
    Arcade modeLobby entry; checks IapData.GetEnterArcade()Full run, stage select, three difficulties, scores and online rankings. See Arcade mode.
    Elena (hero 10007)Selectable only in Arcade modeLevel 30 preset, dual-blade and single-blade forms, seven achievement talents. See Elena and Elena talent tree.
    Arcade preset heroesTerrence, Viola, Benita, Norwood, JeroldSame five heroes as the base game, with fixed attributes and no trophies.
    Seven "Nightmare" opponentsOne per chapter stagePlayer-hero or boss-like Obsessed Ones that grant Elena's special talents.
    Four extra boss stagesStage select onlyTerror Obsession (2001), Guderian the Guardian (2002), Treasure Thieves (2003), The First Fallen: Handel (2004).
    15 achievementsAchievement tab 6See below.
    Outfit "Enigma"Separate item hero11007A cosmetic outfit for Elena. Its description says it can be used in Dance of the Throne. Buying it sets the flag IapData.DLC_ELENA, but no Lua code reads that flag (GetElenaOutfit has no caller), so what it unlocks is decided outside the Lua files.

    The three other add-on outfits in the same shop list, Herald Outfit (Terrence, hero11001), Initiation Rite (Viola, hero11002) and Sleeping Beauty (Benita, hero11003), are cosmetic items for the base heroes and are not part of this add-on.

    How the game gates it#

    • Main menu: the lobby checks IapData.GetEnterArcade() when you try to enter the mode. If it is false, pressing Arcade opens the add-on (DLC) panel instead, and on the very first launch without the add-on the game opens that panel by itself. A text saying the add-on must be bought and activated (UI_ARCADE_IS_NOT_PURCHASED) exists in the language file, but no Lua code that uses it was found.
    • Cross-add-on stages: the stage select blocks stage 2001 (Terror Obsession) without the Dark Mist add-on and stages 2002 to 2004 without the Tides add-on. The messages say the other add-on is required.
    • Elena's logo: the lobby shows an Elena banner for the add-on when the build constant DLC_Elena is true (it is, in xdefine.lua), and the banner is only active if the add-on is owned. The Tides logo is the fallback when that constant is false.
    • Flags in this build: in the Lua files we have, DLC_ARCADE, DLC_ELENA, DLC_MAZE_1 and DLC_TIDE_1 start as true, so every gate is open. The payment callback in sdkhelper.lua also sets each flag to true when the matching product (dlcarcade, hero11007, ...) is confirmed paid, and nothing in the Lua sets them to false. Debug overrides (DebugEnterArcade and the like) can force them on too. Whether the native Steam layer changes the values at run time cannot be seen in the Lua code (inferred).

    Hidden mechanics#

    • Name mismatch. Players and the menu say "Dance of the Throne"; the code, data tables and debug flags say "Arcade". Searching the text for the English name only finds the add-on store text, the Arcade difficulty intro, the "not purchased" message and the achievement tab.
    • Two Elenas share one Chinese name. The playable hero (10007) and the duelling nun boss of Blessedland (20039) both carry the internal name 伊琳娜 (Elena). In Arcade mode the nun appears as a Nightmare opponent that gives Elena her Finale talent.
    • Only Elena's clears unlock. Expert and stage select in Arcade mode need a full clear by Elena herself, see Arcade mode.
    • Elena's stamina-cost talents from this add-on probably have no effect because of a condition quirk, see Arcade mode. That is a reading of the code and has not been verified in play.
