    Game modes

    Arcade mode

    Arcade mode

    Game mode

    Marketed as
    Dance of the Throne (add-on content)
    Heroes
    Elena (default), Terrence, Viola, Benita, Norwood, Jerold
    Difficulties
    Casual, Normal, Expert
    Stages
    7 chapter stages and a finale; 4 extra boss stages in stage select
    Scoring
    Time score (up to 20,000) plus kill score (10,000 pool) x rank multiplier
    Grades
    C, B, A, S per stage and for the whole run
    Unlock
    Expert and stage select need a full clear by Elena

    Arcade mode is the score-attack mode of the Dance of the Throne add-on. You pick a hero, a difficulty and either a full run or a single stage, then fight through a shortened version of each chapter against faster, harder and more heavily scored enemies. Every stage ends with a result screen that grades you from C to S and sends your score to an online ranking. The hero is a fixed preset (level 30, no equipment), so the mode tests execution rather than your save game. The add-on's centrepiece is the playable hero Elena, and the mode is where her seven achievement talents are earned.

    Overview#

    • Entry: the lobby's Arcade entry needs the Dance of the Throne flag (IapData.GetEnterArcade). Without it, pressing Arcade opens the add-on (DLC) panel instead; a "must be purchased and activated" text exists in the language file, but no code using it was found.
    • Modes of play:
      • Playthrough (score key 10080): the full run, eight stages in a fixed order, one life bar, one set of talents.
      • Stage select: replay one stage on its own. Elena starts it with every arcade talent you have already earned.
      • Total High Score (key 9999): a ranking tab only. After each stage-select result the game adds up, for stages 1001 to 1008 and 2001 to 2004, the best record of any hero at that difficulty and stores the sum (CheckTotalRecord).
    • Save slots: the mode keeps its own autosave slot. A restart bumps the story loop counter (ArcadeRestart) and sends you back to the start of the run.
    • Start kit: every arcade run puts a Broken Bronze Whistle (item 90001, the mode's teleport item) in quick slot 1 if you do not have one. The whistle is the only item that is guaranteed.
    • Time out of combat: after a stage boss dies the game enters a "relax time" (inferred: the stage clock stops there), and the next stage is loaded from a carriage point. The final fight ends the run and returns you to the title screen with the result screen first.

    Elena's talents in the mode#

    In a full playthrough Elena is not given her talent tree: the code never maxes her talents, so she has only the nine default-open nodes (DefaultOpen 1; inferred that these start at level 1) and gains seven special talents by killing the seven Obsessed Ones from the Nightmare, one per stage. In stage select she instead starts with all 31 talents of rows 1 to 3 at maximum level, and the seven special talents (row 4, 38 nodes in total) come only from the achievements you already hold. Each special talent is also an achievement.

    The talent names are the Chinese internal names; the English names above are taken from the matching achievement titles, which line up one to one with the talent ids and positions (inferred). The nodes sit in the fourth row of Elena's tree, the row that holds Sanity talents for every other hero (Elena talent tree).

    How they are granted:

    • ControllerStoryMode:AddTalent runs when such a monster dies. It does nothing unless the controlled hero is Elena (10007). It sets the talent to level 1, refreshes stats, and credits the matching achievement.
    • In stage select, InitArcadeHeroTalent hands Elena every one of these talents whose achievement you have already finished, at the start of the stage.
    • In a full playthrough that call is not made, so the talents come only from kills inside the run (inferred: whether talents already stored on Elena's hero from an earlier run carry over was not traced). Killing all seven is required for 60001 (Legacy).
    • Because the stats are PropertyAdd (value 300 = +30% of base, via base * value / 1000) and the talents are summed, the two Health talents together give +60% max Health and the two Stamina talents +50% max Stamina.

    • Casual runs are scored with the Normal stage table but are stored in their own record slot (records are keyed by the difficulty you selected), so Casual, Normal and Expert have separate best scores and leaderboards.

    Extra boss stages (stage select only)#

    Stage select also lists four single-boss stages with story ids 2001 to 2004: Terror Obsession (2001), Guderian the Guardian (2002), Treasure Thieves (2003) and The First Fallen: Handel (2004). Each is a one-monster stage with par time 240 s and a kill-score pool of 10,000, so the whole kill score comes from the boss. The menu blocks the start with a message when the matching add-on is missing: stage 2001 needs the Dark Mist add-on (Deep into the Dark Mist) and stages 2002 to 2004 need Tides of Oblivion.

    The monster table lists all three Tides bosses under story 2002 in the story-monster data (2002068, 2002070, 2002078), so the way 2003 and 2004 load their boss is not visible in that table (unresolved).

    Scoring#

    One stage#

    time score  = min(20000, floor(20000 / (time / standardTime + 1)))
kill score  = sum over kills of floor(10000 * Score / killPool)
stage score = time score + floor(kill score * rank multiplier)
    • time is the stage time in seconds (inferred: cutscene time is tracked separately and not counted). The time score is exactly 10,000 at par, 13,333 at half par, 6,666 at twice par and approaches 0 slowly: speed matters, but the curve is gentle. The ceiling is 20,000.
    • Score is the per-enemy value in ArcadeMonsterProperty (see below) and killPool is the stage's TotalKillScore. A fully cleared stage therefore yields about 10,000 kill score.
    • Rank multiplier: the fraction of the stage's scoring monsters you have killed (dead / MonsterCount) decides it: below 40% it is x0.8 ("white"), 40% to under 70% it is x1.0 ("yellow"), and 70% or more it is x1.2 ("red"). The colour is also the colour of the score digits on the result screen. In stage select the boss counts as one extra kill. Enemies that respawn (the ArcadeRefreshMonsterList ids) and enemies that were summoned by another monster are not scored, and respawning ones and NPCs are not counted either.
    • Grade: score / TotalScore of the stage (Casual uses the Normal column): 100% or more is S, 80% or more A, 50% or more B, otherwise C.

    Whole run#

    For a full playthrough the run score is the sum of the eight stage scores, each computed with its own time and kill data. The overall grade averages the stage grades with S = 4, A = 3, B = 2, C = 1 points: an average of 4 or more is S (so every stage must be S), 3 or more is A, 2 or more is B, below that C. The result is stored under key 10080 for the run, plus a separate record for the last stage.

    What gets rejected#

    MainmenuCtrl.CheckIsValidData throws away a result (no record, no ranking) when the stage score is 32,000 or more, or when the hero's physical damage stat is above 242. 32,000 is exactly the theoretical maximum (20,000 time score at 0 seconds plus 10,000 x 1.2), so a perfect-in-theory run is not accepted.

    Records and rankings#

    Records are stored per (difficulty, hero, story id) and keep the highest total score, using the shorter time as the tiebreak. Each result is uploaded for the online ranking; the module defines a 15-second request cooldown for rank lists. The result screen can show how many "Couriers" you beat.

    Enemy scaling#

    ArcadeMonsterProperty has 156 rows: one per (monster hero id, difficulty table 2 or 3, grade/phase). Unlike Obsession Challenge, almost every row is a level override and a score rather than a stat patch: MonsterLevel replaces the monster's level for the whole mode (level = propertyData.MonsterLevel), and Score is its kill-score weight. Only 19 of the 156 rows carry flat stat changes, in the same format as the challenge table (5 of them on bosses, listed in the table above).

    • Ordinary enemies: 43 of the 74 monster ids are ordinary enemies (the rest are 5 hero opponents, 15 bosses and 11 helpers); 39 of those use level 10 on Normal/Casual and level 15 on Expert. Their Score is 0 to 35: 14 are worth 0, most of the others 5 to 25, and one knight type is worth 35 on Normal and 50 on Expert.

    Hidden mechanics#

    • Elena's talents differ between the two ways to play. Stage select hands her all 31 talents of rows 1 to 3 at maximum (everything except the seven achievement talents), so she is far stronger there than in a full run, where the code gives her no preset talents at all (AddTalentToMaxWithOutSan is called only from ArcadeStageSelect).
    • Only Elena's full clear counts for unlocks. Expert and stage select check hero 10007 specifically.
    • Expert is easier to S than Normal on all seven chapter stages (S thresholds are lower), although its enemies are 5 levels higher.
    • Elena's stamina-cost talents probably do nothing. Fleeting, Eternal War and Demiurge's Wish (17403 to 17405) are type 103 with the condition string "1". The only place the game reads that talent type (Hero10007_Value:GetSkillEnergy) asks for the value with parameters 0 and 0, and MS_HeroTalentCondition:IsConditionPermit rejects any non-skill talent that has a condition when the first parameter is not above 0. The identical effect on Jerold (talent 15210) has an empty condition and works. This is from reading the code, not from testing in game.
    • The Health and Stamina talents have misleading labels. Path of Suffering is described as a greater Health bonus than Shadow Moon, yet both are +30%. The two cost talents Fleeting and Eternal War are described as "slightly reduces" and "reduces" but both are 150.
    • The combo-stamina talent only works after the third consecutive attack (TalentComboAttackNum is 3), like Jerold's.
    • Score cap and the damage cap are anti-cheat. A stage score of 32,000 or more, or a physical damage stat above 242, is silently not recorded. This also means heavily damage-boosted hero builds are not possible anyway, since the hero is a fixed preset.
    • Rank multiplier counts monster deaths, not points. Killing the many weak enemies matters for x1.2 as much as killing a boss, and respawning enemies are excluded so they cannot be farmed.
    • Casual is a damage cut, not an enemy cut. Enemies are the same as on Normal; you simply take 35% less damage, have 130 more Toughness and 20% more base Stamina.
    • Altars in the mode. The altar text for the mode says resting restores health and Health Potions "or obtains new Talents". Only the Nightmare kills were found to grant talents in code.
