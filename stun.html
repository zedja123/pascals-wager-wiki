    Status effects

    Stun

    Stun

    Status effect

    Kind
    Control (logic type 105, Dizzy)
    Duration
    5 s (7 s for one variant)
    Build-up
    30-100% per hit
    Family
    109 (all stuns share it)
    Counts as debuff
    Yes
    Inflicted by
    Frollo, Fused Sprenger, Terror Obsession, some regular enemies, one trick, one trap

    Stun is the game's crowd-control status: while it is active the victim is locked in a "freeze" hit pose and cannot act. In the base game only enemies, one trick and one trap inflict it on the player; no hero move stuns, and the Stun Crystal throwable does not stun either (it only deals heavy weakness damage). There are six stun rows in the status table. They differ only in duration, how fast they build up, and whether they show an icon. It is one of the Status effects.

    Overview#

    • Effect. Each frame the stun is active, the code puts the victim into the Freeze hit state. This only happens if the victim is not already in a different hit reaction, or if it is already frozen. The stun does no damage of its own.
    • Build-up. Most stuns need several hits. Each hit adds a fixed percentage to a hidden gauge, and the stun starts when the gauge reaches 100%. Until then the gauge drains a fixed amount per second.
    • Duration. It counts from the moment the gauge fills (the timer actually starts 0.1 s later, so a 5 s stun lasts about 5.1 s). Hitting the victim again with the same stun while it is active resets the timer to full.
    • Icon. Two variants are hidden (IsShow 0): they freeze you without showing a status icon.

    Hidden mechanics#

    • Blocking does not stop stun build-up. When a hit lands, the game skips its status only if the hit was blocked or parried and the status row has GuardEnable set. Every stun has GuardEnable = 0. So guarding Frollo's bell combo still fills your stun gauge, even though it stops the damage. See Guarding, Parry and counter and the general rule in Status effects#Resistance and immunity.
    • No resistance. The gauge gain is the raw StackAddPer value. No stat, resistance or difficulty setting reduces it (Status effects#Resistance and immunity).
    • Getting hit breaks the stun. When a victim leaves the Freeze state for any other hit reaction (a flinch, knockback, launch and so on), the game clears every stun on it at once. A follow-up attack therefore ends your stun early, though you still take that attack.
    • One stun at a time. All six stuns are in the same family (StatusType 109). A stun with a different ID replaces the current one. If your current stun is already active, the new stun's build-up does not keep you frozen: the active stun is removed and the new one starts as an empty gauge with that hit's build-up. For example, Frollo's toll (10081) freezes you, and if a regular swing (10033) then lands, the freeze ends and you are left with a 30% gauge (the swing's hit reaction would end the stun anyway).
    • A half-built gauge carries over. If a different stun in the same family lands while the current one is still only a gauge (not yet frozen), the old gauge is moved onto the new stun and the new hit's build-up is added to it (AddStatus keeps GetStack() of the replaced status). Only an active stun loses its gauge (activation zeroes it).
    • Repeat stuns reset the timer. The same stun landing again while active resets its duration to full (IsRefresh 1). The trap stun 10112 is the exception: it has ExcludeOther 1, so further applications are ignored while it is active.
    • The drain delay counts from the first hit. The short delay before the gauge starts draining (0.1 s for Frollo's stuns) is set when the gauge is created. Later hits do not restart it.
    • Debuff rules apply. Stuns are flagged as debuffs. While Slightly Sweet Roots' Debuff Immunity is active (10068, 30 s; 10123, 300 s for the + version), no stun can be applied, and eating the roots removes a current stun. See Shields and protection#Other protection.
    • Invincibility does not cancel a stun. Norwood's 1.5 s counter invincibility blocks damage but does not touch status logic (inferred: the stun code never checks it; compare Status effects).

    Related#

    • Poise and stagger: stagger is a different system, based on the toughness and weakness gauges. Stun is a status.
