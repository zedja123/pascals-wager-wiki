    Random trophy properties

    Random trophy properties

    Item mechanic

    Applies to
    17 trophy types (item ids 67001-69517) plus 8 unused test-like items
    Rolled
    Once, when the trophy is created
    Properties
    2-4 fixed stats, random values
    Seed
    Saved per story (new seed after clearing the maze)
    Enhance / Reforge
    Not possible

    Some trophies, mostly those found in Deep into the Dark Mist, carry random properties. Their stats are fixed by the trophy type, but each stat's value is rolled once from a range when the trophy enters your inventory. The roll is permanent: these trophies cannot be enhanced, reforged or used as reforge material.

    How the roll works#

    For each of the trophy's (up to 4) properties the game looks up a range row with a lower bound, an upper bound and a step, then computes:

    value = Lower + Step × R, where R is a whole number from 1 to (Upper − Lower) / Step, drawn by a generator seeded with RandomSeed + RandomTimes (one call per property).

    Pool rowLowerUpperStepPossible values
    50101 Attack (+0)2032121 to 32 (12 values)
    60601 Health (+0)50100555 to 100 (10 values)

    All ranges divide evenly, so the upper bound can always be rolled, but the listed lower bound never can (the smallest roll is one step above it).

    The random number does not come from the clock. It comes from a seed kept in your story save: seed = RandomSeed + RandomTimes, and RandomTimes goes up by 10 on every call, one call per property. A three-property trophy uses three consecutive seeds. RandomTimes wraps back to 0 after passing 999,999.

    Random-property trophies#

    Each type exists at +0 to +5 (all 17 are also listed in the Trophy list, and their level odds per chest in Trophy sources#Dream Chests). Most also come in three effect strengths that share the same stat pools: ids 67xxx (described as a slight effect), 68xxx (moderate) and 69xxx (great). The strengths differ only in the trophy's special effect (LogicParam; see Trophy effects#Random trophies: the Abnormal and Lunatic families).

    Eight more Nightmare items with untranslated Chinese names (67068-67075) also have the random-property flag. They appear in no maze drop list. Each has two pools (for example 67068: Attack and Stamina Regen), and their internal names (such as an attack bonus during abnormal collapse) do not match those pools, so they look like test or cut items.

    Where they come from#

    • Maze drops: the Deep into the Dark Mist drop lists (StoryMazeDrop) contain random-property trophies on every maze level, and the best version on offer rises with depth. Level 1 lists only +0; the highest listed version is +1 at level 2, +2 at level 3, +3 at level 4, +4 from level 7 and +5 from level 16. Levels 10-15 list only +3/+4, and from level 21 on only +4/+5 (counted from drop-list entries, not weighted by their Prob chances).
    • Trophy boxes (Dream Chests) from merchants: buying a "trophy box" item picks one trophy from the box's drop list for the current story, weighted by each entry's Prob. That pick uses the same save seed and counter, and if the picked trophy has random properties, its values use the next seeds in the sequence. The purchase is refused when your trophy inventory is full.

    Hidden mechanics#

    • Rolled at pickup, then frozen. The roll happens when the trophy object is created in your inventory (a drop, a reward or a merchant purchase). The values are written into the save as two lists (RanT types, RanV values) and loaded back unchanged; the game only rolls again if a saved random trophy has no stored values.
    • The level does not change the roll. Each "+N" version is a separate item whose property ids already point at the +N pool rows, so the pool comes from the item id, not from enhancing (which these trophies cannot do anyway).
    • Save-scumming does not help (inferred from the code). The seed and the roll counter are saved with your story. If you reload a save and pick up the same trophies in the same order, they should roll exactly the same values. You can only change the outcome by changing what else uses the counter before the pickup, such as another random-property trophy or a merchant trophy box (inferred from the shared counter).
    • New seed when the maze is cleared. Choosing to return to Mist Camp after the last maze floor (the prompt about the Terror Obsessions being dispersed) rolls a brand-new 5-digit seed (10000-99999). A new story also starts with a new seed. The roll counter RandomTimes is not reset by this, so the sequence of seeds still continues.
    • The bottom of each range is unreachable. For example, an Attack +0 pool row reads 20-32, but the lowest possible roll is 21. Every value in between is equally likely (one uniform draw per property).
    • Consistency check. A developer test save embedded in the game code holds a Raw Gem Amulet +5 (69507) with Attack 93, Crit Rate 14.5% and Crit Damage 14.8%, and Stag Rings +5 (69515) with Stamina 114, Stamina Regen 126 and Crit Rate 12.8%. All six values fall inside the +5 ranges above.
    • Stats stack normally. Random values go into the same stat totals as fixed trophy stats and reforged sub-properties.
